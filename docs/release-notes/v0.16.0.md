Tradr v0.16.0 is out. It adds trading rules, and a set of controls over your own data: take it with you, bring it back, or delete it for good.

Four features this release. If you use app.tradr.cloud you already have it; self-hosters can pull it whenever.

Trading rules are here. Set them up in Settings → Rules. Write down the rules you trade by (max risk per trade, minimum R:R, max daily loss, no trading on Fridays, a cooldown after a loss, and eight more types), weight each one critical, important or nice-to-have, and every position gets a compliance score. Rules score your trades after the fact and never stop you placing one. The position page shows which rules a trade broke. The performance page gets a Compliance panel plus a "By compliance" breakdown.

You can export your whole account now. Settings → Data downloads one zip with every position, fill, ledger entry, tag, screenshot, rule, advisor conversation and your dashboard layout. Import puts that archive back into an empty account, on the same instance or a different one, so moving between app.tradr.cloud and a self-hosted instance works both ways.

You can delete your account from Settings → Account. It asks for your password, and if you're on a paid plan the deletion waits until the end of the period you already paid for (you can cancel it until then). The [account deletion page](https://docs.tradr.cloud/user-guide/account-deletion/) has the details.

The default dashboard is leaner: five widgets, and Open Positions and Account Balances show a handful of rows with a "View all" link instead of growing forever. If you never changed your layout, you get the new one automatically. Adding two widgets in a row no longer fails, either.

Over in the docs, the metrics glossary now shows how each number is calculated, and a new page covers how Tradr itself is built.

Self-hosters: upgrading applies migrations 0036 (account deletion) and 0037 (trading rules) at API boot. Account imports go through the same upload cap as CSV imports, `MAX_UPLOAD_SIZE` (default `20m`), so raise it if your archives are bigger than that.
