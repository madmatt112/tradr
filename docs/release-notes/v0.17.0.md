Tradr v0.17.0 is out. It tracks a multi-leg options trade as one position, does tax lots properly (Canadian pooled ACB included), fits on your phone, and can ask for a second factor when you sign in.

This is a big one, and your tax summary will probably look different afterwards, so read that section before you compare numbers. If you use app.tradr.cloud there's nothing to install. Self-hosters can pull it whenever, but read the upgrade notes at the bottom first, because the web container is stricter about its config now.

## Multi-leg positions

The legs of a spread can now live in one strategy group. Enter them together in the create dialog, or link positions you already have from the position page. Tradr recognises verticals, calendars, straddles, strangles and iron condors, calls anything else Multi-leg, and lets you put your own label on a group.

Close every leg at once from one dialog. The importer spots legs that belong together and proposes groups in the preview, and you choose which ones to keep.

A group counts as one position in your stats, and it goes flat when its last leg does. If you never make a group, your stats stay exactly as they were.

## Tax lots

The tax summary now works from lots. Each fill that opens or adds to a position is a lot with its own price, fee and date.

FIFO is the new default for a US jurisdiction, for "other", and when no jurisdiction is set. Each matched lot gets its own row, and the US short-term and long-term split now runs per lot. To choose which lots a sale closes, pick them in the fill dialog. Want the old figures back? Switch to average cost on the tax summary page.

A Canadian jurisdiction always uses a pooled adjusted cost base: one pool per security and side across all your taxable accounts, with one row per sale. Three things to do if that's you:

- **Mark your registered accounts.** Every account now has a tax treatment, and existing accounts start as taxable. Until you set your TFSA, RRSP or FHSA to registered in the account dialog, its trades land in your pool.
- **Enter your CAD rates.** Tradr won't fetch or guess one. A sale in another currency shows as unpriced until you add the rate for that date under Settings › Profile.
- **Link in-kind transfers.** Moved a position between accounts without selling? Link the two fills from the fill dialog.

Superficial-loss flags now sit on the pool, with a 61-day window around the sale. US wash-sale flags follow the matched lot under FIFO. Both are still notes only, and Tradr never adjusts your cost basis.

All of this stays on the tax summary page. Your journal, account balances and performance figures still use average cost.

## Everything else

Tradr works on a phone. Below 768px the sidebar folds into a menu, and the positions list, the position page, the fill dialog, dashboard widgets and the settings tabs all fit the screen. You can install it to your home screen from the browser too. It still needs a connection; the service worker is there to make it installable and doesn't keep a copy of your journal offline.

The CSV importer has a tastytrade preset. Export Activity › Transactions as CSV and drop it in. The importer now reads a file's headers and suggests the preset that matches, so you may not even have to pick one. Stock and option trades come in, with commissions and fees added together per fill. Cash rows get skipped and the preview says how many. Expirations and assignments don't import yet, so close those positions by hand.

Account imports can't take the server down anymore. A preview or an import stops after 4 minutes with "The archive took too long" and imports nothing, and the server runs one at a time, so a second attempt gets "The server is busy with another import". Wait and try again.

Running Tradr yourself got easier to do properly. There are ready-made Caddy and Traefik overrides that put it behind HTTPS with a real certificate: set `TRADR_DOMAIN` (plus `ACME_EMAIL` for Traefik) and add the override to `COMPOSE_FILE`. The [TLS page](https://docs.tradr.cloud/self-hosting/tls-reverse-proxy/) walks through both. The web container has a `/healthz` check and waits for the API to be healthy before it starts.

The docs picked up new pages on external Postgres, optional integrations, the trade calculator and the dashboard. The demo account's sample trades moved forward 8 weeks so they look recent again.

## Security hardening

Two-factor sign-in is here, and it's optional. Turn it on in Settings › Account with any authenticator app. You get 10 backup codes for when your phone isn't around.

Sign-in locks after 10 failed attempts in 15 minutes. The lock is on the email address and lasts 15 minutes. If your instance can send email, the address gets a link to an unlock page that clears it straight away. If it can't (or someone has lost their phone and their backup codes too), the operator can sort it out from the server:

```sh
docker compose exec api tradr unlock someone@example.com
docker compose exec api tradr disable-2fa someone@example.com
```

The API and the web container now send a Content Security Policy, plus nosniff, `X-Frame-Options: DENY` and a referrer policy. HSTS is off unless you set `HSTS_ENABLED=true`. Only do that once Tradr is served over HTTPS, because browsers remember it for a year.

The option pricing and symbol endpoints are capped at 120 requests a minute per user. CI now fails the build on any high or critical advisory in a production dependency, unless it's on a reviewed allowlist with a review-by date. This release also moves to zod 4 and patches the dompurify and undici advisories.

## Upgrade notes

For most installs, pulling and restarting is enough. A few things changed:

- **The web container checks its config at startup.** It exits with code 1 if `API_BASE_URL` is set and its origin doesn't match `^https?://[A-Za-z0-9.-]+(:[0-9]+)?$`. A value with no scheme, an IPv6 literal or an underscore in the hostname all fail. It also exits 1 if `csp-policy.txt` is missing from the image, which only matters if you build your own. A blank `API_BASE_URL` (the default) is fine.
- **`SESSION_SECRET` is gone.** Nothing reads it. A leftover value is ignored without a warning, so delete it from `.env` when you get a chance.
- **API request bodies are capped at 1 MiB.** A larger one gets a `413`. Position images and CSV and archive imports keep their own larger limits, so this only matters if you script against the API.
- **Account archives are now version 5.** Older archives still import, but one exported from v0.17.0 won't import into an older Tradr.

The new start order and the TLS overrides live in the compose files, so grab the current `docker-compose.yml` (and the override you want) along with the new images.

The API runs 5 new database migrations on its first start. They're automatic, but one builds an index on the ledger, so that first start can take longer on a big install. There are no down migrations, which makes your backup the way back. Take one before you pull.
