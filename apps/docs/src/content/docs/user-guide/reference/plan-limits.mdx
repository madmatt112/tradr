These are the caps on the hosted app. They come from the same table the server
checks against, so what is published here is what is enforced.

| | Free | Pro |
| --- | --- | --- |
| **Accounts** | 1 | Unlimited |
| **Positions** | 1,000 | Unlimited |
| **History window** | 6 months | Unlimited |
| **CSV imports / month** | 10 | Unlimited |

## What each limit means

- **Accounts** — Brokerage accounts you can track at once.
- **Positions** — Stored positions across every account.
- **History window** — How far back the performance charts can read.
- **CSV imports / month** — Import runs, not rows.

Monthly counters reset at the start of each calendar month, measured in UTC.
