## What each limit means

- **Accounts** — Brokerage accounts you can track at once.
- **Positions** — Stored positions across every account.
- **History window** — How far back the performance charts and the advisor can read.
- **Advisor turns / month** — Advisor replies using the platform key. Turns on your own key are never capped.
- **Advisor images / month** — Charts and screenshots you can attach to an advisor conversation.
- **CSV imports / month** — Import runs, not rows.

Monthly counters reset at the start of each calendar month, measured in UTC.

## Bringing your own key

The advisor-turn cap applies to turns that run on the platform key. Add your own
provider key in **Settings** and those turns are uncapped on either plan — you are
paying the provider directly. See [Use the AI advisor](/user-guide/ai-advisor/).
