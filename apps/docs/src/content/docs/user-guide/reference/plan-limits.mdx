When feature gating is on, some actions have usage limits — for example, how many
AI advisor turns you get per month.

<SelfHosted>
  Feature gating is **off by default** on a self-hosted instance, so these limits
  do not apply unless you enable `FEATURE_GATING`.
</SelfHosted>

:::note
The per-plan limits table is not published here yet. It will be generated from
the limits the API enforces, so the page and the product cannot disagree.
:::
