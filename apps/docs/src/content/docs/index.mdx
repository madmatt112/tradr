## Hosted vs self-hosted

Tradr runs the same either way. Where a flow differs between the managed app and
a self-run instance, the docs mark it inline with a **Hosted only** or
**Self-hosted** callout rather than duplicating pages. The
[Hosted vs self-hosted: what's different](/user-guide/explanation/hosted-vs-self-hosted/)
page is the map between the two.

## The state of these docs

Tradr is pre-1.0 and so are its docs. Two guides are complete — [Getting
started](/user-guide/getting-started/) and [Self-host with Docker
Compose](/self-hosting/docker-compose/) — and a number of pages are still
placeholders. Each of those says so at the top, and is kept out of search and out
of search-engine results until it has content.

These docs live in the [product repository](https://github.com/madmatt112/tradr)
next to the code they describe, and every page has an **Edit this page** link. A
correction is a pull request.
