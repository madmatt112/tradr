Tradr reads **80 environment variables**, of which **3 are required** —
everything else has a working default or turns a feature off when unset.

This page is generated from [`.env.example`](https://github.com/madmatt112/tradr/blob/main/.env.example),
the file you copy to `.env`. CI regenerates it and fails if the two disagree, so it
cannot fall behind the template.

## Required

An instance does not start without these three. `docker/quickstart.sh` generates all
of them for you — see [Install with Docker Compose](/self-hosting/docker-compose/).

| Variable | How to generate one |
| --- | --- |
| `POSTGRES_PASSWORD` | `openssl rand -hex 24` — hex avoids the URL-reserved characters that would corrupt the connection string |
| `SESSION_SECRET` | `openssl rand -base64 24` — signs session cookies, minimum 32 characters |
| `ENCRYPTION_KEY` | `openssl rand -hex 32` — a 32-byte key that encrypts stored provider API keys |

:::danger[Keep `ENCRYPTION_KEY` with your backups]
A restored database still holds the provider API keys it encrypted. Without the
original `ENCRYPTION_KEY` nothing can decrypt them. See
[Back up and restore](/self-hosting/backup-restore/).
:::
